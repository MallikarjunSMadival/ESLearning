**ELearning - Embedded Learning Journey**
Welcome to my Embedded Learning repository. This repository documents my journey in learning and developing embedded systems through hands-on projects, practical implementations, and continuous experimentation. 

It covers key areas such as Embedded C, STM32 microcontrollers, device driver development, communication protocols (UART, SPI, I2C, CAN), FreeRTOS, Embedded Linux, Yocto, and Qt application development. 

The goal of this repository is to build a strong foundation in firmware engineering while maintaining a collection of projects, notes, and learning resources. Each project reflects my progress toward becoming a skilled Embedded and Firmware Developer.
